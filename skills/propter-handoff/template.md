# Issue の下書きのテンプレ

下の形を目安にする。節は宛先の repo の Issue テンプレに合わせて足し引きしてよい。

## 題

1 行で、何がどうなるかを書く。宛先の repo の対外文書の言語で書く。

例: `handoff の skill を内蔵する`

## 背景

なぜこの Issue が要るか。会話で分かったことだけを書く。

## 目的

何を達成するか。

## ゴール

達成の形。観測できる形で書く。

## 非ゴール

この Issue でやらないこと。

## 受け入れ条件

- AC-001: （観測できる条件）
- AC-002: （観測できる条件）

## 未決

決まっていないこと。決まっていないと書く。

## 関連

関連する Issue・PR・ファイル。

## 注記

- 会話に無い事実を足さない。
- 決まっていないことは未決として書く。
